# Explore-Understand-Transformer

## Introduction
This repository is a collection of resources to understand the Transformer model. The Transformer model is a deep learning model that has been used in many natural language processing tasks. The model was introduced in the paper [Attention is All You Need](https://arxiv.org/abs/1706.03762) by Vaswani et al. in 2017. The model has been used in many tasks such as machine translation, text summarization, and question answering. The model has been shown to be very effective in these tasks and has been used in many state-of-the-art models.


## Pre-requisites
Install all dependeniencies by running the following command:
```bash
 pip install transformers torch sentence-transformers matplotlib seaborn scikit-learn umap-learn datasets 
``` 
(optional) if you want to use vector DB, faiss, please install it by running the following command:
```bash
pip install faiss-cpu
```
or GPU version:
```bash
pip install faiss-gpu
```
(optional) if you use Jupiter notebook, please install it by running the following command:
```bash
pip install notebook
```
